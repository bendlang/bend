The loader ABI break means the candidate cannot run with the old host. Use a new version of the existing checked matrix tool, leaving prior tools unchanged. It must verify the checked attempts, separately validated per-image Base caches, source/tool hashes before and after each row, process exit/signal/error/timeout/overflow and observed CPU affinity. Compare the entire ordinary adapter result across all six rows, including ordered unsafe definitions, exact diagnostic/output and trust/type metadata. Only hostProvenance may differ: retain every value and verify its exact driver/adapter hashes for each image before excluding that one field from program-observation equality. TypeScript has no such hostProvenance field. Do not normalize any path, whitespace, diagnostic or program output.

Report process time, adapter request time and peak RSS separately. Request timing includes lazy API loading; process time additionally includes startup, frozen-input hashing and capture. This measures usable compiler bundles, so any gain cannot be attributed solely to Bend source changes. Two samples per image provide a screening measurement, not a broad throughput, emission-speed or complete edit-loop claim. No measured improvement is presumed.
