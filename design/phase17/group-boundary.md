The Phase16 oracle proves that a completed parenthesized raw body crosses a
flattening checkpoint which an ordinary row body has not crossed. The raw tree
currently erases this distinction. This experiment restores that information
with one temporary FGroup tag; it does not implement rejection-only frames and
does not claim to fix either observation of monad_do_destructure.

through new f_group_finish. This helper wraps only raw Local/Match/Parallel and
preserves the original node/range inside one unary FGroup. Errors, scalar groups,
tuples and already marked groups retain their existing form. The tuple branch
keeps its current behavior; the independent oracle keeps tuple/body ambiguities
visible. elaborate.bend f_scope consumes FGroup by calling the existing f_scope
on its child with exactly the existing environment/book. Put the check in the
existing final fallback so alias/do/call fast paths are unchanged. No host,
normalizer, backend or compiler ABI change.
