# Execute newly accepted declaration grammar

Freeze three complete Base-importing programs before candidate execution. Each
matches a constructor field and returns a distinct U32 result. The cases cover
an unindented constructor, a comment/newline before its opening brace, and both
features with a preceding zero-field constructor. Every type is followed by an
ordinary definition, proving the declaration terminator and constructor inventory
are usable after parsing.

Run the existing paired backend harness policy against the immutable source04
checked derivative. Select check, interpreter, emitted JS, and native for each
program: twelve exact paired observations. Each source has an independent #|
expected output (41, 42, or 43); compare full reference/candidate observations,
require healthy complete probes and zero exact differences. Preserve any failure.
These are program behavior controls, not a speed benchmark or full backend gate.

The thin runner copies the previously consumed Phase19 backend gate and changes
only the CPU mask to2, report label, and explicit three-case/twelve-row assertions.
It retains the frozen backend environment and unchanged compiler/runtime/host,
cache, subprocess and observation-health guards. No compiler source changes.
