# Compact analysis: prospective repeated-query experiment

2026-09-30. Baseline is actual checked07 at `5f3015d`. Phase31 added107.77ms
(6.90%) to its normal edit-distance request; that observation does not attribute
the cost to emission. A compact representation is a hypothesis, not the result.

Instrument the frozen generated checked07 API, retaining normal `D.inspect`
library loading/checking/reachability/annotation/emission. During the emitter
export only, count calls and exact argument-identity repeats for `wnf`,
`j_arm_type`, primitive/native type checks, local-type checks, scalar/local Nat
shape checks and root/region planning. Include complete arguments (book, type,
mode, active set, fuel and arity where present). Identity misses are conservative:
structurally equal but newly allocated terms will not count. Repeated calls do
not by themselves establish a useful speedup.

Take nested-inclusive diagnostic durations only for coarse admission/planning
helpers, resolving their existing trampoline result before return. Compare every
emitted byte and complete status/error/dependency observation with unmodified07.
No clean speed ratio may use an instrumented run. Inputs: original edit-distance,
Mandelbrot and the H positive source; include a rejected source for error-path
equality. Derivation, input identities and wrapper list are frozen before CPU2
acquisition, outer120seconds, one-million counted calls/request, bounded raw
reports. Root owns all emitter production code; this investigator changes none.

If a small family has many identical queries and material attributed work,
prototype request-local memoization of those pure functions in saved generated
code, with full argument identity and fresh cache per emission. This is a compact
per-request analysis experiment using existing terms; it introduces no permanent
IR. Verify exact output first, then request a separate clean timing window.
If no meaningful improvement survives, reject the larger compact-IR rewrite.
Any future production plan must store all context in its key, preserve fuel and
refusal behavior, retire repeated work, and justify its additional representation
and memory with measured compiler-request gains.
