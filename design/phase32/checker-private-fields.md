# Separate private projection-copy ablation

Prospective follow-up after the completed direct-call screen, 2026-09-30.
Root authorizes correctness CPU6, with another exclusive timing window required.
No production change follows from this plan.

The [first experiment](checker-direct-calls.md) retains project/slice/force and
finds only a modest lookup signal; the second helper shows no demonstrated gain.
Now use four independent saved-output variants: baseline; direct calls only;
private field reads with original callOwned/apply/force; both rules. All keep
H17's original public module as an exact byte prefix. Private copies and data
remain diagnostic, ordinary immutable finite constructor graphs.

The new rule replaces only the recognized unary projection callback
`function(a){return project("Owner",a[0]).slice()[i];}` with
`function(a){return a[0].a[i];}`. Its static proof is an ordinary constructor
representation for the exact KDef/KEnv/KChecking/KWorld owner, with a dense own
field vector produced by the fixture constructors. No native tuple layout is
assumed. The original fields contain fully demanded values and no getters,
proxies or mutable vector; retaining force on the selected value is intentional.
This rule removes the copy, not its value demand. For the fields-only variant,
private fn wrappers retain normal saturated calls, generic application and
forcing; only their projection body differs. Do not combine the rules silently.

Replay every complete independent lookup/checker oracle, input/result identity
and public isolation check. Add a specific copy-order counterexample: accessing
an unselected field while the old slice snapshots it can mutate another field.
The new private direct read would omit that effect, so public admission is
explicitly refused. Preserve the previous descriptor-mutation witness, and
execute the wrong-index derivative against the same full-value oracle.

Freeze a new four-role timing plan after controls pass, keeping the original
batch workloads and clear first-run/warming limits. Rotation and exact bytes
must be explicit. If the second helper still has no useful gain, retain it as
negative evidence rather than finding a friendlier replacement workload.

Independently inspect the compiler host adapter as a possible trusted boundary.
Freshly encoded graphs alone are insufficient if callbacks, lazy view unwrapping,
mutable public G, reentry or descriptor access can occur during the invocation.
Identify the smallest enforceable owner/lifetime contract and its producer cost.
No omission of a runtime guard, widening of recursive-type admission or special
compiler-name recognition is authorized by this private experiment.
