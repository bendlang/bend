# Private producers after private folds

Phase35's checked09 symreg profile places 64.33% of sampled CPU ancestry under
`gen`, `gen.leaf` or `node`. The private consumers already have explicit iterative
folds. Hypothesis: saturated private producers can remove the remaining runtime
function wrappers and matcher dispatch while retaining the public tagged tree.
This is a generated-program hypothesis, not a compiler-throughput claim.

## Discriminator

`producer-derive.mjs` reads only the frozen checked09 symreg module and creates
three matched variants. Baseline keeps its emitted body. Generator substitutes
an iterative dynamic-Nat implementation of `gen` in **only the existing guarded
cand branch**, retaining generic `node` and `gen.leaf`. Producer also emits their
finite choices and tagged constructors directly. The full original `bench(6,42)`
remains the timing point; no depth-five specialization or consumer changes occur.
A separate `producerPoint` exercises varying depths and complete tree outputs.

The original runtime public gen/node/leaf descriptors, currying, mutation
fallbacks and exact cand entry remain. The current host guard and complete
captured dependency guard execute before producer entry. One reusable frame per
active Nat depth records the parent seed, remaining depth, phase and left result.
The second child's seed is evaluated only after the first child returns. The
node tag is chosen after both return. Constructor layout stays `{$,a}`. No
memoization or subtree rewriting changes sharing. JavaScript recursion is absent.

Run inherited independent opcode/postfix oracles, all complete Sel fields and
unchanged full benchmark outputs; partial entry, fake entry, getters, mutation,
reentry, prototype/intrinsic changes and generated foreign-tree controls. Add
complete private output oracles over multiple depths/seeds and positive/negative
entry counters. Then compare baseline/generator/producer/TS in fresh serial
processes, rotated with maintained clean worker. A >3% disjoint regression or
any output/event mismatch rejects promotion. Keep all artifacts.

## Compiler path

First implement the smaller discriminator if it wins: a private `JProducer`
plan for two ordered Nat predecessor selfcalls. Reuse existing `j_tree_shape`,
frame push/argument staging and expression planner. The existing public scalar
tree optimization cannot accept this directly: gen returns a sum, its two lets
are sequential, and its combiner uses a saved parent seed. Normalize exactly two
single sequential lets only when the right RHS does not reference the first
binder; preserve left-to-right order. Retain parent scalars in the existing frame
and restore fresh immutable aliases before the combiner. Every helper input is
native scalar, the output is the already admitted closed fold sum, each recursive
first argument is the exact predecessor, and the independent `JPure` proof plus
region planner validates reachable definitions. No public ADT argument boundary
is added. Functions, native arrays, erased/dependent fields, foreign actions,
partial calls and unproved cycles refuse this plan.

The first integration can leave node and leaf as `JGeneric` residuals. This is
valuable evidence: it isolates recursion/argument-container removal from
constructor admission. Only if the second saved-output ablation adds meaningful
benefit, extend existing region constructors to the same closed sum type and
extend finite-Nat prefix choices across trailing parameters. That requires
separate complete-selector/refusal controls. Avoid a separate tree IR, universal
specializer or an assumed equivalence between purity and demand.

An actual compiler candidate must emit the marker from its own checked source,
pass fixture admission/refusal controls, and improve the unchanged symreg point.
Then re-run full maintained points, normal compilation costs and inherited broad
integration before installing. The intended simplification is reuse of existing
tree and region machinery; record actual added lines and generated bytes.

## Counterexamples and boundaries

Reject a right RHS that observes the first child, nonpredecessor recursive depth,
a recursive result escaping into function/native-array fields, erased live
arguments, missing/refutable constructor branches, foreign callbacks and changed
captured gen/node/leaf/prng identities. Count exact entry to avoid inactive wins.
Shallow complete trees prove values, not unbounded depth: add an independently
owned unary producer or direct generated frame fixture with a deep linear chain
if the two-child subset is later generalized. The binary production subset has
exponential output; a 100,000-depth binary test would be an OOM test, not useful
stack evidence. Its emitter must visibly contain an explicit loop and no direct
self-call and include feasible depths 0–12. A future unary extension needs its own
20,000-depth witness before claiming deep linear support.

The existing closed-region host boundary assumes standard intrinsics at import
and named post-import mutation controls. This proposal does not enlarge that
claim. Allocation/GC, stack/resource exceptions and all JavaScript observability
under arbitrary pre-import monkey-patching are not a universal equivalence proof.
