# Phase16: prove the exact Base freshening boundary before optimizing it

This is a prospective operation/equality experiment, not a compiler or cache
change. Bind the frozen wave4-source-02 implementation and its checked build02.
The stage-matrix-01 API timers are attribution clues, not speed-ratio evidence.
The successful source check never constructs diagnostic origins. It does add
host span-validation walks, while the loader still aliases, elaborates, checks
frontend errors, and globally freshens the complete book. The checked Base alone
has 28,780 KTerms, 528 KDefs and 115,649 decoded objects; global freshening rebuilds
those terms after the exact same Base has been validated and cached.

## Frozen probe

Create a private project differing only in its exported probe entry points;
perform a genuine checked B1/equality build. No compiler function body, cache
schema, or installed default changes. Export existing freshening/graph functions.
Verify every original Bend module is byte-identical to wave4-source-02.

Read the probe compiler's own checked Base cache. Invoke the existing
`f_fresh_defs(Base, 1)`, record its actual `FFreshDefs.next`, and require the entire
returned book to equal the cached book, including every source interval. Never
substitute `norm_max_book + 1`: that routine includes nonbinder token IDs.

For each finite graph, retain the raw graph book, ordinary authoritative graph
result, complete freshened book and next counter. If and only if its leading
definition sequence equals the exact Base book, compare the full freshening with
`Base ++ f_fresh_defs(suffix, BaseFresh.next)`. Require complete term/range/list
order equality and equal final next. A non-prefix Base occurrence must be reported
as ineligible, with the ordinary path unchanged. A absent/mismatched source seed
must exercise the existing seed matcher/fallback, not be silently trusted.

Controls cover a normal Base import, an alias to one physical dependency,
repeated aliases, imports with Base first versus a declaration module before
Base, no Base, duplicate declarations, a valid imported law fill and an invalid
fill, and a malformed declaration. Keep reference error ordering and all failed
controls. Use CPU1, fixed Node24.18.0, 4MiB stack and 4GiB heap. This experiment
makes no elapsed-time or production eligibility claim.

Count the exact number of KTerms, binders, definitions and list/object nodes in
Base, raw graph and suffix. A separate instrumented generated-API probe may count
actual worker visits/allocations only after the equality law holds; instrumentation
is never installed and its timing is not a speed comparison. The first decision
is whether the invariant is true and removes enough repeated work to justify a
later bound cache metadata/ABI proposal.

## Bounded actual-workload extension

After all eleven finite controls and counted outputs pass, run one additional
control on the exact frozen compiler source bound by stage-matrix-01. Compare
complete full/split graph terms and ranges and final fresh-next, and count the
same workers. This determines the removable operation fraction on the actual
workload; instrumented/concurrent elapsed times are not performance evidence.
