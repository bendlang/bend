# Phase16: measure the memo growth boundary before selecting a key fix

Source06 is unselected. Its 16 materialized-name controls match pinned TypeScript,
but `comptime/err_grow_double` moves from the pinned `grow~9` refusal to `grow~10`.
The scoped identity encoding became shorter after replacing global IDs with
lexical IDs. Do not tune the cutoff, add source-dependent padding, or hide this
first-error regression behind unchanged checker rejection.

Create two isolated probe projects from sources05 and06. Change only their host
export lists to expose existing pure key, term-shift/application, bound and
specializer-state workers. Build each through the genuine checked workflow;
keep these APIs explicitly experimental and never select them for installation.
No pinned TypeScript or compiler implementation changes. Every probe binds
source/API/pin/tool identities before and after execution.

For the actual grow-double fixture, inspect the real memo strings in the failed
local state and pinned `book.tmps`. Reconstruct the closed argument sequence
using each implementation's existing substitution/lowering operations, and
require reconstructed entries to equal the actual stored keys at every already
minted level. Then record the first over-limit key, native UTF16 length, local
String length, and byte identity. Compare normalized structural shapes at the
boundary, not merely aggregate key lengths. Capture size data and bounded
summaries rather than printing giant strings into the conversation.

Pinned keys follow `term_lower` after higher-order application/substitution;
they remove spans, rebase IDs and preserve names, quantities, literal forms and
annotations. Local substitution also beta-reduces applications when rebuilding.
Check this stage equivalence explicitly before designing a new size function.
A correct logical-length guard may avoid constructing a second giant string only
if all information needed by the pinned JSON form survives the core. Identify
lost literal/syntax distinctions as hard boundaries; do not approximate a size
function while claiming exact upstream semantics.
