# P30-030 performance decision and timing boundaries

This amendment freezes the performance decision before measuring the isolated
registration-dispatch variants. It supplements
`registration-free-exact-dispatch.md` without changing that derivation's scope,
source, complete-state checks, ABI observations or intrinsic assumptions.

Promote a runtime repair only if maintained confirmation shows at least a 5%
reduction in RLE time versus unchanged checked16, with disjoint five-sample
ranges. Preserve every sample, failed observation and half-drift statistic.
Registered helper128 and original Mandelbrot are negative controls: no slowdown
greater than 3% beyond sample variation is acceptable. A null result or overlapping
ranges do not establish a gain. Source size or static call counts cannot replace
the timing result.

The cheap general-row negative control uses the same no-greater-than-3% slowdown
criterion. Its retained complete-state adapter compares all four arrays over 28
independent inputs before timing; only the flag's audited runtime edits differ.

Freeze an initial screen on the original RLE point with Phase29, unchanged16,
the registration-free direct diagnostic, general monotone flag and pinned
TypeScript. Screen unchanged16 versus flag at helper128 in the same maintained
protocol. An optional complete-state row is included only if its independently
checked derivative and cheap oracle already exist; it is not a reason to delay
the primary discriminating test. Use the existing 15-second warmup runner for
the original Mandelbrot registered negative control; do not use its short
transfer window to claim settled throughput.

All timed modules retain their original public exports. Instrumented counters,
runtime control exports and independent-oracle adapters stay out of timed
modules unless an existing complete-state fixture explicitly defines that
public measurement boundary. Bind all derivation and correctness reports into
the configuration before root grants the exclusive CPU3 window. Other
acquisitions, figures, builds and process-heavy work must be idle during timing.

The checked16 matrix remains immutable and held: RLE's 10.30% regression and
tree-bitonic's separately confirmed 4.15% regression are retained regardless of
this experiment's result. A generated-JavaScript diagnostic is not a new checked
compiler or an installation. Any selected production change needs fresh checked
emission and independent review before its transfer is claimed.
