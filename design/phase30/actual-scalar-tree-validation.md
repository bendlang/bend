# Validate the actual scalar-tree compiler emission

The generated-output tree experiment establishes the opportunity. The next gate
uses actual checked attempt12 output against checked attempt11, whose ordinary
scalar-root optimization is already present. Retain the original attempt10
prototype evidence separately; do not relabel it as a compiler result.

An adaptation tool will verify both emission and attempt receipts, retain their
hashes, and copy byte-identical baseline/candidate modules into a new immutable
directory. It will adapt the existing independent mathematical tree oracle,
130 ordered host observations and eight depth sentinels to two variants. Only
the test harness variant labels and emitted fast-body marker parser change;
the mathematical expected values and host actions remain unchanged. Preserve
the exact adapted test source alongside its originating maintained tool.

Depth sentinels must replace the candidate's actual fast block only after its
original exact permission, slot reads, type checks, predecessor bound and live
closure guard. Replace the adjacent generic body independently. Determine the
block end with balanced delimiters, not a regex spanning arbitrary semicolons.
The resulting diagnostic modules are never timed. Public depths 1 and 32 must
select fast; 33 and a coercible raw predecessor must select generic.

Adapt the separate instrumentation to actual `$frames`, `$top`, `$value` and
`$visit` output. Keep administrative operation counts unchanged. Verify node,
leaf, combine and frame counts, high-water and complete small leaf index order.
The instrumentation must identify exactly one admitted original-program tree
owner and assert each replacement count. No instrumentation is placed in the
candidate used for timing.

The actual compiler may choose different lexical names or closure guard order.
Tests must compare complete public results/events and mechanisms rather than
requiring identical prototype spelling. All instrumentation and sentinel copies
stay separately hashed. Compiler analysis itself must recognize checked term
shape and types, never the fixture name.

Independent review owns additional metadata, primitive-marker and copied-vector
controls, plus source admission/refusal tests. Those gates are required before
promotion. After all semantic gates pass, freeze a new actual11/actual12/TypeScript
original-small timing comparison and a paired depth-five component comparison.
Use the maintained protocols under a new exclusive timing grant. Preserve the
existing prototype's intra-sample throughput change; a compiler result must
carry its own drift evidence.
