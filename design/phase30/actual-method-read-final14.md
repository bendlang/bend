# Renew actual-method authorization on candidate14

Prospective independent discriminator for the held candidate14 release. The
original-ten matrix reports regressions on several generic programs alongside
the large Mandelbrot improvement. This experiment renews the previously tested
actual-method-read intervention on the exact checked14 bytes. It does not combine
ordinary-call inlining, generic matcher rewriting, callback fusion, or a change
to entry-token representation.

The sole replacement is `invokeExact`, using the exact `NEW` function from
`inspect-exact-call-read.py` and requiring it to match the retained
`inspection-exact-call-01/derive.json` function text. The mechanism and proof are
in [the original design](exact-entry-call-read.md). In particular, a registered
ordinary callback's actual `code.call` value, read once before `f.env`, authorizes
entry if it equals the captured native method. This removes the conservative
prototype/descriptor reflection. Custom callable methods receive their original
receiver and arguments; the rare noncallable facade retains the raw `code.call`
error selector. The unregistered branch, `apply`, token consumption/restoration,
matcher bodies, scalar guards, and generated arithmetic remain unchanged.

An own or inherited accessor returning the captured native method deliberately
changes the private permission flag from false to true. The flag is diagnostic
state, not the public equivalence oracle. Getter/trap order, raw reentrant entry,
values, exceptions, copied-vector demand and fallback behavior must remain equal.
Keep the existing stable-intrinsic scope; do not claim transparency to replacing
`Reflect.apply` or the private WeakSet's standard methods.

`inspect-actual-method14.py CONFIG FRESH_OUT` accepts the same checked-module map
as the independent inline-exact experiment. It verifies emission receipts against
the selected attempt and its exact runtime prefix, freezes the original and
changed modules, and proves byte-for-byte reverse reconstruction. Initial inputs
are the actual14 scalar helper and the five original generic/Mandelbrot modules.
Fresh checked14 and Phase29 owned-row emissions will be acquired separately from
the same source; append them through a new immutable configuration, never by
relabeling the older actual13 fixture.

Before timing, renew the retained 91 method/error/matcher observations, 121 scalar
points, 146 ABI/prototype observations, 72 scalar cases, nine entry controls, and
the 34 additional dispatch/order/reentry observations. The controls adapter keeps
the explicit `[[false],[true]]` accessor-native permission expectation. Compare
complete owned-row states and the unchanged original edit-distance/Mandelbrot
results. Preserve failed attempts and raw TypeError text without normalization.

Root controls execution and timing grants. The first timing window should compare
Phase29, actual14, and each independent runtime variant on the small full-state
owned row; helper/original-Mandelbrot results bound scalar regressions. Renew any
original generic point with the original transfer protocol if attribution warrants
it. The earlier 7% original-edit-distance screen and drifting 9% row confirmation
remain historical evidence, not an estimate for this new image. No production
runtime change or compound speedup is implied by this experiment.
