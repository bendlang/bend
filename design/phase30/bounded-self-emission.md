# One complete self-emission after the final gates

Prospective Phase30 follow-up. The parent authorized one bounded current
compiler B1→H acquisition after final release and clean comparison gates. It is
not an H→H fixed-point experiment and cannot change the installed default.
The [static feasibility note](../../implementation/phase30/self-emission-feasibility.md)
records the existing adapter/ABI path and historical resource observations.

Freeze a final attempt directory, its verified bootstrap report's exact assembled
source, selected API, checked parent, Base, runtime, Node and complete frozen
driver/helper identities. Bind the unchanged `phase26/emit.mjs` and its workflow
dependencies. The source must match `sourceSha256` and be an attested artifact,
not a freshly assembled approximation. Reverify these inputs after every child.

The single emission uses CPU2, Node24.18.0, 4MiB V8 stack, 8GiB heap and an outer
**1,200-second** process-tree deadline. Record actual OS stack, affinity, start,
end, peak RSS if available, status/signal, complete stdout/stderr and generated
module hash/size. Enable ordinary phase tracing for localization. The output
directory is fresh; retain a timeout or failure without retry or budget increase.
No other clean timing may overlap this acquisition. The deadline applies to the
one emission, not to a silently started reproduction chain.

Before the expensive child, use the same frozen B1 driver to check and emit a
small Nat/U32 wraparound fixture, execute its output and require8. Require a
Bool-as-U32 fixture to reject at checking. These source bytes and the independent
unsigned recurrence are frozen in the plan. The positive fixture is explicitly
unsafe only for its recursive implementation; no independent proof-kernel verdict
is requested. B1 preflight has a90-second child limit. A preflight failure stops
the experiment and survives unchanged.

After successful emission, require JavaScript syntax acceptance and ABI versions
load2/term1/span3/check2. Configure the same driver with the actual emitted H API
and unchanged Base/runtime. Its existing positional-ADT adapter must suffice;
no extra source transformation, equality derivative or hand-edited H is allowed.
Prepare a Base cache genuinely checked by H under a separate90-second cap,
then run the same positive library emission/execution and negative check under
another90-second cap. Require the same B1 observation fields and result8.
Use a separate10-second cap for each emitted small program if it executes in a
child; retain all exceptions, outputs and identities.

Successful H input modules and its small output are derived experiment artifacts,
not development-attempt manifests. Record explicit B1→H and H→small-program
provenance. H timing includes its ordinary host ABI conversion and cache handling;
one acquisition is no controlled compiler-speed ratio. No fixed point, complete H
conformance, kernel proof, stage3, or release promotion follows from this gate.

`inspect-self-emission-plan.py FINAL_ATTEMPT FRESH_DIRECTORY` creates only a
frozen configuration and oracle source files. It executes no compiler/program.
Defaults reflect the above budgets and can be overridden only prospectively in a
fresh plan. The root must explicitly grant execution after the release/timing
priorities; creating a plan is not that grant.
