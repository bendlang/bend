# Compose only independently checked runtime interventions

This is a prospective fallback plan, not authorization to execute a combination.
The root may choose a single winner first. If the independent held14 runtime
screens justify a combined experiment, derive it from the same untouched checked14
origin; never patch an already transformed module or multiply isolated speedups.

Use mechanism names to avoid ambiguous letter labels:

- `inline_exact`: the two retained `apply`/`invokeExact` edits from
  [ordinary-call inlining](inline-unregistered-exact-entry.md).
- `actual_method`: the one `invokeExact` replacement from
  [actual-method authorization](actual-method-read-final14.md).
- `generic_matcher` or `fused_matcher`: mutually exclusive replacements of the
  same original `matcher1p` from
  [the matcher experiment](partial-prebinding-registration-ablation.md).

`inline_exact` plus either matcher intervention has disjoint original ranges.
`actual_method` plus either matcher intervention also has disjoint ranges.
`inline_exact` plus `actual_method` overlaps `invokeExact` and is deliberately
refused by this tool. Combining those requires a separately reviewed merged
function, not an automatic textual composition. The two matcher variants are
likewise mutually exclusive.

`inspect-runtime-compose.py CONFIG FRESH_OUT` consumes the selected checked14
attempt, module/checked-receipt map, and completed independent derivation receipts.
It accepts only the known exact edit schemas above. Every selected old range must
occur once in the attested original runtime; overlapping ranges are rejected.
Construct the new runtime from original offsets and record both original and
output ranges. Reverse those offsets to recover every original byte. Every module
must begin with the same attested runtime and have a checked receipt bound to the
same attempt/API/runtime/Base; all generated suffix bytes remain identical.
Retain independent gate reports as input evidence and stop if any selected gate
does not report complete/pass. Runtime derivation does not itself constitute a
combined correctness gate.

After derivation, renew the 146 ABI/prototype +72 scalar cases, nine entry cases,
34 dispatch traces, 91 method/matcher/error traces, 121 independent helper points,
and original exact edit-distance/Mandelbrot results. Keep the actual-method private
permission expectation only when that intervention is selected. For generic
matcher composition, use the reviewer's original delayed matcher as the semantic
reference for any inherited current14 scheduling difference; retain those
differences separately. Do not silently redefine a failing public observation as
equivalent. Renew all 28 complete-state row points and the retained alias/effect
boundaries on the combined bytes.

Only then freeze a new same-window comparison containing unchanged Phase29,
unchanged checked14, the useful isolated variants, and the combination. A direct
comparison determines interaction and profitability. Small-row success remains
attribution evidence until maintained integration passes selected original-program
transfer and fresh relevant correctness gates. No source edit is part of this
composition tool.
