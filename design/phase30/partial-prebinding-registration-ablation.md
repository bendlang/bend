# Separate partial prebinding savings from entry registration cost

The final original-program window shows regressions on several generic
workloads. This prospective experiment isolates a possible contributor:
matcher1p now allocates a registered exactCode callback wrapper and inner
closure, then pays exact-entry dispatch for every selected constructor arm.
It is separate from moving unregistered invokeExact work back into apply.
No source or runtime edit is authorized by this diagnostic design.

Partial arity alone does not permit eager prebinding. The retained
`review-prebind-entry-01` witness already uses two fields and a three-argument
arm. Even without entering the arm body, copying the projected vector can
invoke foreign slice/getters before an enclosing copied-length observation,
and a raw caller observes bounce versus partial-descriptor shape. Returning a
partial descriptor on every invocation would reintroduce that defect.

The smallest safe no-token experiment is to restore the generic delayed
application for this helper only:

```js
function matcher1p(name,count,arity,make){
  return fn(1,([x])=>{
    const p=project(name,x),n=p.length,c=make();
    return n?jump(fn(arity,c),p):fn(arity,c);
  });
}
```

Projection, its first length read and literal code construction keep their
order. The public callback stays an anonymous, nonconstructible length1 arrow.
It returns the same original unsliced-field bounce or zero-field descriptor as
matcher1 plus the corresponding literal arm. Generic apply owns all subsequent
field copying, malformed lengths, partial/exact/oversaturated scheduling and
code.call behavior. The count parameter becomes unused, preserving call-site
shape and generated code. Runtime data formats and all public emitter output
remain unchanged; no new bounce kind or hidden descriptor side map is added.

This restores an extra arm descriptor/bounce/application, so it may lose more
than it saves. Test it rather than assuming registration cost dominates.
Compare actual14 complete editdist, a cheap full-array row, and scalar/whole
Mandelbrot as appropriate, holding every other helper and generated byte fixed.
Retain exact reconstruction and frozen source/runtime/attempt identities.

Semantic gates use both the literal matcher1 reference and current14. Require
the original raw/exact/partial/oversaturated/copy/error/call-hook behavior.
Retain any additional original generic observations under globally patched
prototype hooks as explicit historical-prebinding differences, not normalized
successes. No arbitrary patched-intrinsic equivalence is inferred. Keep full
ordinary ABI, callable shape, projected-vector, saved-bounce and actual-program
controls before timing. A nontrivial supported-scope mismatch stops promotion.

A separate discriminator fuses entry consumption directly into one
fresh registered anonymous arrow, removing the inner wrapper closure/call but
retaining the exact token. This does not solve registration cost and must not
be combined with the generic-bounce experiment. It must consume the token before
destructuring and preserve name/length/arrow kind. After token consumption use a
literal `return (([x])=>{...unchanged body...})(a)` call. This keeps destructuring
in the same formal-parameter form, including malformed non-iterable errors,
while exposing the body call directly to the host optimizer instead of routing
all fresh closures through shared enterExact. Keep the body and all its control
flow unchanged. This may replace a construction-time closure with a call-time
literal that V8 eliminates; allocation and speed effects require measurement.
The earlier scalar-worker fused experiment does not establish matcher costs.

The fused variant reuses the exact private registry and token record. Its
inline code/vector/used predicate and consume-before-destructure step are
copied verbatim from enterExact for this disposable experiment. If promoted,
factor shared consumption only after proving the actual maintained output and
cost; do not introduce two long-term permission policies. No invocation/guard
or generic-application change belongs in these variants.

`review-prebind-variants-controls.mjs` records 97 ordinary differential cases:
all generic results/traces must equal the literal matcher reference, and all
fused results/traces must equal current14. Generic/current differences are
recorded separately, including in ordinary supported cases; an original behavior
restoration must not be rejected merely to preserve an inherited14 defect. They cover
partial/exact/raw/forged/oversaturated entry, projected/custom/copied vectors,
length and slice throws, malformed noniterable callback frames, saved partial
call hooks, public callable kind, and iterator/slot/environment/slice reentry.
`review-prebind-prototype-diagnostic.mjs` separately records all24 combinations
of six Object.prototype hooks and four throw thresholds. It collects every
case before asserting fused/current and generic/original equivalence. It does
not assert or label generic/current ambient-prototype equivalence, and retains
any value/error differences as well as the raw hook counts and ordered traces.
This diagnostic mutation is explicitly outside the existing standard-intrinsic
scope. A generic/original or fused/current discrepancy blocks promotion. Any
generic/current discrepancy is individually classified against the original
matcher contract; matching original behavior may be a correctness repair. No
inherited optimization defect is made normative solely because14 contains it.
