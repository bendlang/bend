## Objective and research transfer

Improve generated program execution substantially while keeping checked compiler
iterations fast and the implementation understandable. Distinguish three axes:
compiler request cost, complete edit/build/test turnaround, and execution of
compiled user programs. Zig history will be studied through versioned official
release notes and maintainer/source records in [zig-lessons.md](zig-lessons.md).
Self-hosting, a faster debug backend and high-quality generated code are different
achievements. Do not transfer a Zig benchmark multiplier to Bend.

The leading generated-program hypothesis is that larger guarded local regions,
followed by demand-aware removal of record shells, remove whole runtime layers.
Phase30's native-call ladder improved1.759× but remained40.6× TypeScript on its
specific complete-row fixture. Residual force/projection/construction counts
identify candidate mechanisms, not CPU shares. Existing checked17 remains the
ordinary installed compiler during prototype work.

small-request deficit against its genuine TS-produced parent of the same Bend

## Phase D: smallest general implementation

A winning generated transformation must be expressed by checked Bend source,
using existing KTerm and bounded region analysis where possible. Start with
scalar public boundaries and closed, internally produced records/Array<U32>.
Local aliases are permitted. No container can arrive through globals or escape
through returned closures/foreign effects. Original function/native identities
and runtime assumptions are guarded once at entry, before any private work.

Keep demand explicit: a field containing Array.set must execute at the original
point and in original order. Constructor knowledge alone cannot justify eager
forcing, eliminating writes or replacing shared handles. Initially keep native
storage and public representation. Unknown shapes, unproved recursion and
exhausted shared budgets fall back through existing semantics. Do not grow one
recognizer per benchmark. A small typed region plan is justified only if it
replaces duplicated reasoning/emission rather than becoming another pipeline.

Each source change requires a genuine checked B1,36 focused observations,
fresh emission, independent semantic controls and at least one second source.
Keep API/parent/H identities separate. If a prototype cannot be generalized
safely, retain it as prototype and pursue the next measured hypothesis.
