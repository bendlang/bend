# P14-004: integrated conformance and workflow gates

Status: prospective validation policy, before the integrated candidate or full run.
The [main design](../../design/phase14/conformance_and_dispatch.md) owns the phase.
The root tools bind existing Phase12 and unchanged-pin reference vectors.

The full frontend gate classifies every changed observation as a new exact
reference match, an intended parse/proof-trust transition for the four named
imported-law cases, or a checker diagnostic containing only added caret rows
with all semantic/output fields unchanged. Existing exact matches may not regress.
Every other difference fails the gate and remains retained for investigation.
Independent renderer tests establish caret placement; deleting caret rows is
only a delta-classification check, never the exact-conformance oracle.

Require all1,001positive type accepts, all482validation-negative refusals, all11
intended proof-trust refusals, no missing/invalid/timeout observations, unchanged
later-emission acceptance and fewer exact reference differences. Strict outputs,
raw results and semantic triage are retained separately. The new renderer's71/78
strict family result remains failed for seven pre-existing span errors.

Imported-law declaration ordering may require exactly two reviewed typed-driver
call-site substitutions: driver_report and driver_bad_names consume loaded.book
rather than the specialized book. The Phase14 same-source matrix explicitly
binds this host difference while requiring identical compiler ABI and candidate/
upstream adapter bytes. This measures each release workflow; it is not attributed
solely to Bend evaluation speed. Original source order, final dependency lookup
and unspecialized template trust need independent controls before integration.
No arbitrary host drift is allowed. The unchanged Phase8 timing worker and
Phase9 process/identity/semantic assertions remain in use.

The independent source-dispatch pilot retains identical hosts and same frozen
source. If selected, the combined candidate needs new scoped and full gates;
individual controls do not automatically establish combination correctness.
