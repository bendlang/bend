# Scalar-region runtime snapshots and guards

Implemented under the prospective
[general scalar-region plan](../../design/phase30/scalar-region-compiler.md).
Reviewer owns only the additions to `selfhost/src/runtime/js/core.mjs`; the root
regenerates the combined runtime and builds the compiler. These results test
the runtime helpers directly and do not establish compiler admission correctness.

`scalarCapture(name, descriptor)` records metadata from a freshly constructed
compiler wrapper in a private null-prototype table, then returns the exact
descriptor. It adds no public properties and preserves identity. Capture occurs
before G assignment, so mutations before the first public call cannot become
the reference snapshot. Forward/missing G definitions make the guard decline.

`scalarGuard(names)` accepts only the captured own G data binding and original
ordinary descriptor, arity, code, null environment and empty bound-array
identity. Metadata accessors, replacement objects, changed prototypes, io and
typeName paths, code.call overrides and changed Function.prototype.call all
decline without invoking those hooks. Replacement Proxies are rejected by
identity before their properties or prototype are inspected.

The guard also checks relevant primitive prototype hooks: request, bounce,
build and code on Object/Boolean/Number/BigInt prototypes, plus ordinary
prototype links. This strengthens the initial generated-JS prototype's scope:
a primitive request/forcing hook now selects fallback rather than being skipped
by private code. General built-in function monkeypatching remains outside the
standard-intrinsic contract; these checks are not a sandbox or a general purity
test for arbitrary JavaScript functions.

Capture arguments are trusted newly constructed compiler wrappers; guard name
arrays are private compiler-generated literals. Capture is not an API for
introspecting arbitrary foreign Proxies. Guarding the private captured ordinary
objects and their own data descriptors is what makes validation observation-free.

## Independent controls

`selfhost/tools/performance/phase30/review-scalar-runtime.mjs` passes 46
observations against the production core source. Its append-only diagnostic
module, exact consumed tool, input hashes and outcomes are retained in
`selfhost/build/phase30/review-scalar-runtime-01/`.

Coverage includes exact identity/shape preservation; before-assignment and
forward definitions; mutation before first use; a `__proto__` name; metadata,
G-entry and code.call accessors; replacement Proxies; code/arity/env/bound
changes; frozen original descriptors; prototype hooks and altered prototype
links; Function.prototype.call accessors; and a Number.prototype.bounce witness
that is correctly observed by the fallback forcing path. All guarded getters
and Proxy traps remain uninvoked during validation.

No compiler API or combined runtime image is regenerated by this subtask.
Generated-region admission, scalar input checks, complete dependency closure,
checked source controls and performance remain separate integration gates.
