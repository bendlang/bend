# Independent review of the small generated-compiler timing protocol

Static review finds no blocker in the prospective
[warmed request design](../../design/phase30/warmed-generated-compiler-cost.md)
and its plan, worker and supervisor. No preparation, request or timed process
was executed by this review.

The baseline is the genuine checked parent API `60aa968f…`, generated by the
pinned upstream compiler from the same attested assembled Bend compiler source.
It is distinct from the selected equality API `33545640…` used for the earlier
B1→H acquisition. The other side is the actual retained H `21b53c69…`, bound by
its completed emission and functional-oracle receipts. This compares two
**generated compiler programs**, not H directly against the implementation of
the upstream TypeScript compiler.

Each API obtains its own genuinely validated Base cache, keyed by its actual
API hash, Base hash and canonical Base path. Preparation proves checked-library
output bytes equal the separately retained program and executes result8. The
measurement phase binds those preparation/cache receipts and refuses mutation
before or after trials. Cache labels are not transferred between API identities.
The frozen driver loads H through the real positional ADT adapter; that conversion
remains in the request cost. A common emission-runtime input does not imply that
the two compiler programs have identical embedded runtime representations.

Fresh serial trials alternate both sides three times on CPU0. Each process uses
a single loaded API, one untimed warm request and two timed ordinary D.inspect
library requests. The driver still performs normal source discovery, checking,
Base-cache reading and emission within each request; imports, explicit Base
preparation and output hashing/execution are outside its timer. Each emitted
program must retain the expected hash and each trial's complete non-code
observation must equal its own preparation. Both sides' preparation observations
also agree. The90-second process cap includes setup and all three requests.

The proposed report keeps all six trial means, individual warm/measured values,
within-trial changes, ranges, process observations and RSS. One fixed warm request
and one tiny fixture cannot establish steady-state compiler throughput, a full
selfcompile ratio, complete H conformance or a fixed point. A slow or drifting
sample remains evidence; the protocol must not silently rerun it until a desired
ratio appears. Preparation and exclusive timing require separate parent grants.
