# Final-Boolean branch-loop experiment: preparation record

The research/review agent prepared the
[prospective design](../../design/phase35/branch-regions.md),
[saved-output producer](../../selfhost/tools/performance/phase35/branch-derive.mjs)
and [independent controls](../../selfhost/tools/performance/phase35/branch-controls.mjs).
No compiler build, program execution or timing was run by that agent. This record
does not claim that those controls pass or that the prototype improves performance.
Root's acquired results and any subsequent corrections must remain separate.

The bounded target is the original raytrace `nearest.t` final successor Boolean
callback. Keeping the existing Nat and leading-lambda stages avoids the known
arity/partial-application flaw in the rejected flattened public wrapper. The
prototype retains generic intersection/selector work, giving one isolated direct
recursion mechanism. Scalar/dependency guards alone are insufficient while those
helpers still execute generic Array operations; an initial hook-descriptor guard
is therefore included before the existing guard.

The prepared producer pins its input module, parses/verifies the expected shape,
retains original expression slices, records all producer/module identities and
refuses to overwrite an acquisition. The paired control producer uses two module
instances with restoration between mutations, avoiding a large collection of
fresh imported instances. Its independent formula covers values, while separate
public-stage observations cover calls, descriptors, hooks and errors.

Promotion is undecided. Saved-output prototypes remain separate from the compiler
implemented in Bend, even if an execution screen is favorable. The new 1,000-ray
checksum point is a fast mechanism screen; original raytrace and the maintained
broader suite remain the transfer targets.


## Control revision and admission witness

Root executed the original producer and first control acquisition. Its report at
`selfhost/build/phase35/branch-controls-01/report.json` stopped after 143 oracle
points and 61 completed boundaries at `final-entry:new`. Both variants threw a
TypeError without semantic events, but V8 printed the changed callback source
inside its nonconstructor error message. This is not claimed as a complete pass.

The original tool and acquisition remain unchanged. `branch-controls-v2.mjs`
normalizes only that explicit constructor probe's engine-produced callback-source
prefix, requiring TypeError and the same ` is not a constructor` suffix. It keeps
raw error evidence, values and ordered semantic events. No other boundary error
is normalized. Exact `Function.prototype.toString` equality is not the callback
ABI being tested; nonconstructibility, name, length and own properties are.

`branch-witness.mjs` creates a separate diagnostic derivative with one admission
counter immediately inside the guarded fast region. Its checks require one
admission per complete nonzero nearest call, zero for the original Nat zero arm,
and matching baseline checksums for 1 and 1,000 calls. The derivative must never
be used for timing. Neither revised tool was executed by the research agent.
