## Semantic boundary

The reference's first depth-first constructor wins: inspect the head constructor before its children, children before later siblings; ordinary definitions with the same name never win but their nested constructors remain reachable during initial construction. Include arbitrary nested constructor books, not just production-shaped ADTs. A miss must return the complete original Missing(name) payload, not the index's private Absent sentinel. Returned definitions must retain the original reference identity and complete fields.

Index construction intentionally traverses the immutable forest once. It is not equivalent to the old per-query demand or arbitrary effectful getter sequences.
