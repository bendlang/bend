## Cause and implementation

Pinned `bend2/bend.ts` checks an erased binder through `parse_name`; `f_erased_local` previously constructed a reference from any token. The candidate guards it with the existing `f_valid_name` and reports through `fpe_error`. It neither changes valid erased binders nor treats prefix minus as a numeric operator.

Pinned `book_load` validates local path spelling before opening files. The Bend parser previously concatenated import-path tokens without that spelling check, so a dotted filename, tilde or local hub-shaped directory reached filesystem resolution first. Six small definitions implement the local plain-segment grammar and contextual missing-file rendering. Import terms carry their original path-token line and column in previously unused numeric fields. No new datatype or intermediate marker is introduced. Leading `./`, absolute `/`, repeated leading `../`, ASCII identifiers and hyphenated segments follow the pinned local rules; interior dot segments and repeated interior separators are refused. The path validator intentionally leaves existing raw hub/package requests outside its scope. The current host has no hub/package fetch implementation, and this phase adds none.

The IO host catches **ENOENT from an imported dependency** or its own active-traversal cycle signal, asks the generated Bend API to render the message using the existing `dg_snippet`, and marks that contextual failure as parse. The shared `f_import_failure` helper chooses the missing-file or cycle message; both use one location implementation. A missing entry file and EACCES retain their original IO failures. Nested failures retain the dependency's context. The new renderer is feature-detected for historical compiler APIs. Its bootstrap export is source-detected.

Import precedence also required a host-order correction. Discovery previously threw a parent parser error before visiting the imports returned alongside it. It now visits earlier valid imports first, then throws the parent parser error, matching the pinned import-before-body order in the tested controls. The final host also tracks active canonical IO paths, distinguishing a traversal reentry from a completed physical alias before pending body errors or later imports are considered. Language diagnostic text stays in Bend; supplied-source graph APIs retain their own cycle check. This bounded IO traversal guard is documented separately from the compiler's graph validation. No universal cycle/stack claim follows.
